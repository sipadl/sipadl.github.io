# 🌐 sipadl.github.io

Personal developer portfolio website. Modern minimal design showcasing projects, skills, and contact information.

![HTML](https://img.shields.io/badge/HTML5-E34F26?logo=html5)
![CSS](https://img.shields.io/badge/CSS3-1572B6?logo=css3)

## ✨ Features

- 🎨 **Clean Design** — Modern minimal aesthetic, no heavy gradients or glassmorphism
- 📱 **Responsive** — Mobile-first layout, works on all devices
- 🚀 **Fast** — Pure HTML/CSS/JS, no framework overhead
- 🔗 **Project Showcase** — Links to all GitHub repositories
